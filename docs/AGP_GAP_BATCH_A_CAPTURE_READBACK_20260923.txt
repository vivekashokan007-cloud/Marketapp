AGP / Android upload-readback gap (Batch A capture completeness)
================================================================
Date: 2026-09-23 IST

Android Gradle Plugin is not available in this executor runtime, so Kotlin
upload → persisted snapshot → readback cannot be executed here.

Enforced instead:
  - Python producer → _compact_android_snapshot_context → JSON round-trip
  - Over-budget payloads marked forward_capture_budget_exceeded_batch_a
  - Incomplete required fields marked forward_capture_incomplete_batch_a
  - Per-field present/missing/truncated inventory in snapshot_capture_field_status

This is the strongest available contract without AGP.
